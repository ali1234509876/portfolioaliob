A machine learning project that predicts possible diseases based on symptoms described in text. The system uses Natural Language Processing (NLP) and a pre-trained BERT model to understand the meaning behind symptom descriptions and identify the most likely diseases. It aims to assist doctors, nurses, and patients by supporting faster diagnosis, reducing human error, and enabling early disease detection.
