A machine learning project focused on detecting and interpreting American Sign Language (ASL) gestures using computer vision techniques. The system analyzes hand gestures from images or real-time input and classifies them using machine learning models to translate ASL signs into understandable outputs. The project aims to reduce communication barriers and support more inclusive interaction between ASL users and non-users.
